# 志愿者入组指南

欢迎加入 2026 大会志愿者项目。

本指南适用于已经确认参与本次大会现场志愿服务的成员。

请按照本页面的顺序完成入组。完成全部要求后，项目负责人会将你的项目状态更新为：

**READY（准备完成）**

---

## 一、确认 GitHub 访问权限

请首先确认：

- 可以正常登录 GitHub
- 使用的是准备参与本项目的 GitHub 账号
- 可以访问项目仓库
- 可以正常查看项目 README 和相关文档

项目仓库：

`conference-volunteer-ops-2026`

如果无法访问，请及时联系项目负责人。

> 当前仓库可能暂时由项目负责人个人 GitHub 账户托管。
> 后续仓库转入 Organization 后，成员可能需要重新确认 Organization 邀请或访问权限。

---

## 二、确认 GitHub Username

每位志愿者需要向负责人提供自己的 GitHub Username。

例如：

`@username`

请注意：

GitHub Username 与昵称、显示名称不同。

请以个人 GitHub 主页中的用户名为准。

---
