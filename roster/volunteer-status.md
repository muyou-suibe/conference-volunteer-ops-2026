# 志愿者状态跟踪表

本文件用于跟踪 2026 大会正式志愿者的项目准备状态。

> 本表只记录项目协作所需的非敏感信息。
> 身份证、银行卡、家庭住址、详细联系方式、内部筛选评价等信息不得记录在本文件中。

---

## 状态说明

| 状态 | 含义 |
|---|---|
| 待确认 | 已进入正式人员池，但部分信息尚未确认 |
| 待邀请 | 已确认参与，等待 GitHub 邀请 |
| 已邀请 | GitHub 邀请已发送，等待接受 |
| 已加入 | 已成功进入项目协作空间 |
| 入组完成 | 已完成入组指南要求 |
| 培训完成 | 已完成规定培训 |
| 待排班 | 可参与日期已确认，等待正式安排 |
| 已排班 | 正式工作日期已确定 |
| 岗位确认 | 已确认岗位及工作区域 |
| READY | 活动前全部准备完成 |

---

## READY 判定标准

只有同时满足以下条件，最终状态才可以更新为 `READY`：

- GitHub 访问正常
- Volunteer ID 已确认
- 可参与日期已确认
- 入组完成
- 培训完成
- 正式排班已确认
- 岗位已确认
- 已知晓集合要求
- 已知晓现场沟通及异常升级方式
